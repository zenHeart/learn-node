# OS 模块

操作系统信息，CPU、内存、网络接口、平台等。

## 主要功能

- CPU 信息（cpus /arch /loadavg）
- 内存信息（totalmem / freemem）
- 网络接口（networkInterfaces）
- 平台信息（platform / release / type）
- 用户信息（userInfo）
- 临时目录（tmpdir）
- 主机名（hostname）
