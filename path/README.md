# Path 模块

跨平台路径处理，Windows 和 Unix 路径兼容。

## 主要功能

- join() 拼接路径
- resolve() 解析为绝对路径
- dirname() / basename() / extname()
- parse() / format() 路径解析
- sep 分隔符
- normalize() 路径规范化
