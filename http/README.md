# HTTP 模块

Node.js HTTP 服务器和客户端，Web 开发的基础。

## 主要功能

- 创建 HTTP 服务器
- 处理请求和响应
- 发送 HTTP 请求
- WebSocket（通过 http 模块）
- 静态文件服务器

## 示例列表

| 文件 | 说明 |
|------|------|
| 01-server.js | 基础 HTTP 服务器 |
| 02-router.js | 简单路由实现 |
| 03-client.js | HTTP 客户端请求 |
| 04-parse-url.js | URL 解析 |
| 05-static-server.js | 静态文件服务器 |
| 06-middleware.js | 中间件模式 |
