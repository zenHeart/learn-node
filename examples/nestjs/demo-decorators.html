装饰器映射

装饰器提取来源示例
@Get('/cats')—路由
@Query('page')URL ?page=1查询参数
@Param('id')URL /cats/:id路径参数
@Body()Request Body请求体
@Headers('auth')Header请求头
@Cookies('sid')CookieCookie
@Ip()RequestIP 地址
 
@Controller('cats')
export class CatsController {
  @Get()
  findAll(@Query('page') page: number,
             @Query('limit') limit: number) {
    return { page, limit };
  }

  @Post()
  create(@Body() dto: CreateCatDto) {
    return this.catsService.create(dto);
  }
}

常见装饰器速查

@Get(@path?)
处理 GET 请求，可指定路径
@Post(@path?)
处理 POST 请求
@Put/@Patch/@Delete
PUT/PATCH/DELETE 请求
@Body(@key?)
提取请求体，可指定字段
@Query(@key?)
提取查询参数
@Param(@key?)
提取路径参数
@Headers(@key?)
提取请求头
@HttpCode(code)
自定义响应状态码
@UseGuards(...)
应用守卫
@UsePipes(...)
应用管道验证
@Injectable()
标记为可注入 Provider
@Module()
定义 NestJS 模块
