# Stream 模块

流式处理，数据像水流一样流动，适合处理大文件或持续数据。

## 主要概念

- Readable Stream（可读流）
- Writable Stream（可写流）
- Duplex Stream（双工流，可读可写）
- Transform Stream（转换流）
- pipe() 管道连接
