# Crypto 模块

Node.js 加密解密支持，Hash、HMAC、AES、RSA、对称加密等。

## 主要功能

- Hash（MD5、SHA-1、SHA-256 等）
- HMAC（带密钥的 Hash）
- 对称加密（AES）
- 非对称加密（RSA）
- 随机数生成
- 签名验证

## 示例列表

| 文件 | 说明 |
|------|------|
| 01-hash.js | Hash 计算 |
| 02-hmac.js | HMAC 计算 |
| 03-aes.js | AES 对称加密 |
| 04-rsa.js | RSA 非对称加密 |
| 05-random.js | 随机数与 UUID |
| 06-password.js | 密码哈希实战 |
