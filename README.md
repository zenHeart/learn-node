# Learn Node.js

Node.js 核心模块学习仓库，收集核心模块的使用范例和实战项目。

## 模块列表

| 模块 | 说明 |
|------|------|
| [buffer](./buffer/) | 缓冲区，处理二进制数据 |
| [crypto](./crypto/) | 加密解密，Hash、HMAC、AES、RSA |
| [events](./events/) | 事件发射器，观察者模式 |
| [fs](./fs/) | 文件系统，读写文件、目录操作 |
| [http](./http/) | HTTP 服务器和客户端 |
| [net](./net/) | TCP/UDP 网络编程 |
| [os](./os/) | 操作系统信息 |
| [path](./path/) | 路径处理和转换 |
| [stream](./stream/) | 流处理，pipe 管道 |

## 快速开始

```bash
# 进入目录
cd <module-name>

# 运行示例
node 01-basic.js
```
